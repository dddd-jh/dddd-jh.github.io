02 / OPEN SOURCE

以复现、测试和评审积累贡献。

evo：移除 ROS bag 轨迹读取中的第二次扫描及额外原始消息缓存，增加 ROS 1／ROS 2 回归测试。本机全量 126 项测试及 2 项子测试通过。

small_gicp：修复串行、OpenMP、TBB 体素降采样错误保留越界点的问题。原生 C++ 的 16 项回归测试修改前 7 项失败，修改后全部通过。

KISS-ICP：修复过滤 NaN 点后逐点时间戳错位的问题。19 项新增回归测试和 6 组真实 ROS bag／原生畸变补偿检查通过。

RKO-LIO：修复激光／IMU 排序器在输入结束时丢弃已覆盖激光帧的问题。11 项新增排序测试及全部 53 项 Python 测试通过。已按维护者反馈精简为一行补丁，并于 2026-10-05 被上游合并；原回归用例留存本机。

KISS-SLAM：修复二维地图导出的尺寸和方向错误，保留 ROS 坐标约定下的栅格位置。13 项实际 PNG／YAML 回归测试通过，并加入上游 CI。

MapClosures：修复二维闭环配准的反射修正与平移计算，保证合法旋转。9 项原生 C++ 回归测试修改前 5 项失败，修复后全部通过，Release CTest 连续五轮通过。

GLIM：修复全局定位时间晚于已有里程计时的轨迹索引越界，保留全局变换和插值样本。8 项原生 C++ 测试在启用边界检查时原实现 6 项越界终止，修复后全部通过。

gtsam_points：修复邻域搜索结果对临时索引回调的悬空引用，保留引用捕获行为。12 项原生 C++ 回归测试原实现 8 项失败，修复后全部通过；上游 Linux/GCC 完整构建及全部 98 项 CTest 已通过，其他取消配置仍未验证。

MCAP：修复 ROS 2 Time／Duration 内置备用定义的秒数符号错误，支持负值正确编码和解码。50 项新增测试原实现 24 项失败，修复后全部通过；四个 Python 包共 119 项测试通过，1 项 Windows 管道测试未完成。

Ouster SDK：修复无符号激光时间戳在轨迹插值与外推中的减法溢出，保留纳秒精度。52 项新增测试原实现 14 项失败，修复后全部 67 项相关测试在 NumPy 1.x／2.x 与无 SciPy 实现下通过，并验证原生激光帧和点云变换。

pytransform3d：修复默认时序位姿查询在最后采样时间的数组越界，保留越界拒绝规则。21 项新增回归用例原实现 10 项失败，修复后全部通过；NumPy 1.x／2.x 下全部 49 项变换管理器测试通过。全仓库结果及已有精度测试失败见 PR。

pytransform3d：修复指定时间查询失败后污染管理器当前时间的问题，保持异常传播并恢复后续查询行为。15 项新增回归用例原实现 13 项失败，修复后全部通过；NumPy 1.x／2.x 下全部 43 项变换管理器测试通过。

KISS-ICP：修复组织点云忽略行末填充导致后续行坐标及逐点时间戳错误的问题。19 项新增回归用例原实现 11 项失败，修复后全部通过；9 组真实 ROS1／ROS2 SQLite／MCAP 文件及原生去畸变检查通过。与已有 NaN 时间戳修复合并后的 39 项测试通过。

MCAP：修复 ROS2 同一话题切换消息定义时错误复用旧通道的问题，确保数据与解码定义匹配，返回原定义时仍复用原通道。7 项新增回归用例原实现 6 项失败，修复后全部通过；四个 Python 包共 76 项测试及 3 组独立解码器文件检查通过，1 项已有 Windows 管道测试被排除。上游 Linux Python 完整测试、lint、示例、构建及 Python 一致性检查已通过。

SpatialMath：修复四元数对数丢失小角度姿态增量的问题，保持批量、非单位四元数及负标量主值分支。新增 3 个回归方法、12 项子测试；NumPy 1.x／2.x 下完整测试均为 350 项通过、3 项跳过，300 组 SciPy 独立对照检查通过。

KISS-ICP：修复 HeLiPR 读取丢失文件最后一个完整点的问题，保留不完整尾记录处理。20 项新增测试原实现 15 项失败，修复后全部通过；NumPy 1.x／2.x 下完整 Python 测试均为 21 项通过，10 组生成文件经原生去畸变检查通过。

manif：修复小角度 SO(3) 对数的四元数符号不一致，保证 SE(3) 位姿对数及 Jacobian 一致。4 项新增测试覆盖 48 组场景，修复后通过；完整核心 C++ 套件 17 个 CTest 程序、5,064 项测试通过，C++11 独立检查通过。

pytransform3d：修复批量四元数乘法在原地／重叠输出时破坏姿态组合的问题。28 项新增测试、完整批量旋转模块 151 项测试通过；两套 NumPy 环境的独立 SciPy 比较及连续姿态组合通过，全库的既有容差失败已记录。已提交十八项 PR，其中 evo、RKO-LIO、pytransform3d #385／#386 共四项已合并；评审进展、验证环境及 CI 状态见各 PR。
